# 🌸 EstudiaPro

### Organizador de tareas académicas

EstudiaPro es una aplicación desarrollada con React Native y Expo para organizar las materias y las tareas académicas durante la semana. Su objetivo es ayudar a los estudiantes a mantener sus actividades ordenadas, identificar las tareas pendientes y registrar las que ya fueron entregadas.

La aplicación cuenta con una interfaz visual de colores pastel, un fondo floral y tarjetas diseñadas para ofrecer una experiencia sencilla, agradable y fácil de utilizar.

## ✨ Funcionalidades principales

- 📅 Organización de materias de lunes a viernes.
- 📚 Consulta de las materias correspondientes a cada día.
- ✍️ Registro de tareas asociadas a una materia.
- 📋 Visualización de tareas pendientes.
- ✅ Cambio de estado entre pendiente y entregada.
- 🎨 Diseño personalizado con colores pastel y fondo floral.
- 📱 Interfaz adaptable a dispositivos móviles y navegadores web.

## 🛠️ Tecnologías utilizadas

- **React Native:** construcción de la interfaz de la aplicación.
- **Expo:** desarrollo y ejecución del proyecto en dispositivos y navegador.
- **JavaScript:** programación de las funciones y la interacción.
- **React Navigation:** navegación entre las diferentes pantallas.
- **Git y GitHub:** control de versiones y almacenamiento del código fuente.
- **Vercel:** publicación de la versión web.

## 📖 Conceptos de programación aplicados

El proyecto integra conceptos utilizados durante las prácticas de desarrollo móvil:

| Concepto | Aplicación en EstudiaPro |
|---|---|
| `View` y `Text` | Organización de los elementos y presentación de textos. |
| `StyleSheet` | Definición de los estilos visuales. |
| `Pressable` | Creación de botones y selección de días y materias. |
| `TextInput` | Escritura de las descripciones de las tareas. |
| `useState` | Control de datos y cambios en la interfaz. |
| Stack Navigation | Navegación entre las pantallas de la aplicación. |
| `ImageBackground` | Incorporación del fondo floral. |
| `ScrollView` | Desplazamiento por el contenido de las pantallas. |

También se incorporaron ajustes para facilitar la escritura con el teclado y adaptar la presentación a distintos tamaños de pantalla.

## 🚀 Cómo ejecutar el proyecto

Necesitas tener Node.js instalado en tu computadora.

**1. Clonar el repositorio**

```bash
git clone https://github.com/cataU213/EstudiaPro.git
```

**2. Entrar en la carpeta**

```bash
cd EstudiaPro
```

**3. Instalar las dependencias**

```bash
npm install
```

**4. Ejecutar la aplicación**

```bash
npx expo start
```

Para probar la versión web localmente:

```bash
npx expo start --web
```
## 🎓 Propósito académico

EstudiaPro forma parte de un proyecto académico orientado a aplicar los conocimientos de desarrollo de aplicaciones móviles mediante React Native y Expo.

Durante su elaboración se trabajó con componentes de interfaz, estilos, eventos de pulsación, entrada de texto, manejo del estado y navegación entre pantallas.

El proyecto busca demostrar cómo estos conceptos pueden integrarse para desarrollar una aplicación útil para la organización de las actividades estudiantiles.
